# yuda.dev Nuxt Yeniden Yazım — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** yuda.dev'i Nuxt 4 ile statik, yerel SEO odaklı bir site olarak sıfırdan kurmak: yerel hizmet sayfaları, script ürün sayfaları, ileri tarihli yayın destekli blog.

**Architecture:** Nuxt 4 `nuxt generate` ile tamamen statik çıktı (`.output/public`) üretir. İçerik (hizmet, ürün, blog, yasal) Nuxt Content v3 koleksiyonlarında Markdown + Zod şemasıyla tutulur. Saf iş mantığı (`app/utils/*`) Vitest birim testleriyle, üretilen HTML ise `tests/build/*` altındaki build testleriyle doğrulanır.

**Tech Stack:** Node 24, npm 11, Nuxt 4.6, @nuxt/content 3.17 (native sqlite), Tailwind CSS 4.3 (@tailwindcss/vite), @nuxtjs/seo 6 (sitemap, robots, schema-org, og-image, seo-utils), @nuxt/image 2, @nuxt/fonts 1, @nuxt/icon 2 (Lucide), Vitest 5, node-html-parser, linkinator 8.

**Spec:** `docs/superpowers/specs/2026-11-21-yuda-nuxt-design.md`
